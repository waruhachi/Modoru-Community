# Modoru

Modoru runs App Store apps on iOS versions below their minimum, the ones that refuse to install because they need a newer iOS. The goal is iOS 14 through 26; right now it targets jailbroken iOS 16, with iOS 17 next.

## Request an app

Want an app supported? [Open an app request](https://github.com/waruhachi/Modoru-Community/issues/new?template=app_request.yml) with the app's name and App Store link.

## Compatibility tracker

The [project board](https://github.com/waruhachi?tab=projects) tracks which apps work, which are in progress, and which can't be supported. Check there before requesting.

## Status

Early development. Beta testers on jailbroken iOS 16 are welcome, and the source code will be published here when it's ready.
